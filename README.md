## Task overview

### 1. Recon
Information gathering: host discovery, port scanning, service and version enumeration, and mapping the attack surface.

### 2. Exploit known vulnerabilities in network services
Identifying vulnerable service versions, matching them to known CVEs / public exploits, and gaining an initial foothold.

### 3. Web application hacking
Finding and exploiting common web vulnerabilities (injection, authentication and access control flaws, file upload, etc.).

### 4. Privilege escalation
Moving from a low-privileged user to higher privileges on Linux/Windows targets through misconfigurations, weak permissions, and vulnerable services.

### 5. Network routing traffic
Analyzing and manipulating how traffic is routed between networks, including routing configuration and traffic inspection.
